# 014. Learning — ScriptService / RecommendedScriptSelector / ScriptController + REST Docs (2 엔드포인트)

## Goal
스크립트 상세와 일일 추천 스크립트를 노출한다. 추천은 결정론적 셔플(시드 = userId + KST 일자) 로 동일 시드 → 동일 결과 보장.

## Prerequisites
- 013: learning-track-service-controller-restdocs

## Acceptance Criteria
- [ ] `com.capstoneecho.echo_back.learning.script.support.RecommendedScriptSelector` 가 `select(userId, kstDate, scripts, count): List<Script>` 제공. 시드 = `Objects.hash(userId, kstDate.toString())`. 같은 (userId, kstDate, scripts) 입력 → 같은 출력 보장.
- [ ] `ScriptService` (`@Service`, `@Transactional(readOnly=true)`):
  - `getScript(scriptId): ScriptDetailResponse` — 미존재 `SCRIPT_NOT_FOUND`. 스텝이 0개면 `STEP_NOT_FOUND` (정책 명시: 스크립트는 최소 1개 RECORD 스텝 필요).
  - `recommendToday(userId): List<ScriptSummaryResponse>` — preset 스크립트에서 결정론 선택.
- [ ] `ScriptController` (`@RequestMapping("/api/scripts")`, JWT 필요):
  - `GET /recommended/today` — 200.
  - `GET /{scriptId}` — 200 / 404.
- [ ] DTO: `ScriptDetailResponse(id, title, content, difficulty, practiceWord, masteryBadgeName, steps: List<StepResponse>)`, `StepResponse(id, kind, prompt, targetText)`, `ScriptSummaryResponse(id, title, difficulty, preset)`.
- [ ] 단위 테스트: `RecommendedScriptSelectorTest` 가 동일 시드 → 동일 결과 + 다른 일자 → 다른 결과 검증 그린.
- [ ] 컨트롤러 테스트 `ScriptControllerTest` 2건 + REST Docs 스니펫(`scripts/recommended-today`, `scripts/get`) 그린.
- [ ] `./gradlew test --tests ScriptControllerTest --tests RecommendedScriptSelectorTest` 그린.
