# 002. Foundation — JwtProvider / JwtPrincipal / @CurrentUser

## Goal
HS256 기반 stateless JWT 발급·검증과 `Authentication` → 도메인 사용자 ID 추출을 표준화한다. 모든 보호 엔드포인트가 의존.

## Prerequisites
- 001: foundation-api-response-errors

## Acceptance Criteria
- [ ] `com.capstoneecho.echo_back.global.jwt.JwtProvider` 가 `issue(userId, additionalClaims)` 와 `parse(token)` 메서드 제공. 알고리즘 HS256, 만료 `AppProperties.jwt.expirationMs`(기본 3600000 = 1h), 시크릿 `AppProperties.jwt.secret`.
- [ ] 토큰 만료/위조/형식오류는 각각 `BusinessException(INVALID_TOKEN)` 으로 변환.
- [ ] `JwtPrincipal(userId, username, email)` record 도입.
- [ ] `@CurrentUser` 어노테이션 + `CurrentUserArgumentResolver` 가 컨트롤러 메서드 파라미터에 `JwtPrincipal` 주입. 인증 컨텍스트 없으면 `BusinessException(UNAUTHORIZED)`.
- [ ] `JwtProviderTest` 가 issue→parse 라운드트립, 만료, 위조 시그니처 케이스 그린.
- [ ] `./gradlew test --tests JwtProviderTest` 그린.
