# 011. Member — AuthController / MemberController + REST Docs (7 엔드포인트)

## Goal
Member 도메인의 7개 HTTP 엔드포인트를 노출하고 MockMvc + Spring REST Docs 로 스니펫을 생성한다. M2 (Auth Live) 마일스톤.

## Prerequisites
- 008: member-service-profile-nickname
- 010: auth-service-oauth2-google-demo
- 006: foundation-health-controller-restdocs

## Acceptance Criteria
- [ ] `AuthController` (`@RestController`, `@RequestMapping("/api/auth")`) 엔드포인트:
  - `POST /signup` — 201 + AuthTokenResponse 봉투.
  - `POST /login` — 200 + AuthTokenResponse 봉투.
  - `POST /check-username` — 200 + `{available}` 봉투.
  - `POST /check-email` — 200 + `{available}` 봉투.
  - `GET /oauth2/google/demo` — 200 + AuthTokenResponse 봉투(데모, 멱등).
- [ ] `MemberController` (`@RequestMapping("/api/members")`):
  - `GET /me` — JWT 보호. `@CurrentUser JwtPrincipal` 주입.
  - `PATCH /me/nickname` — JWT 보호. `@Valid NicknameUpdateRequest`.
- [ ] 컨트롤러 테스트 7건 (`AuthControllerTest`, `MemberControllerTest`) 모두 `AbstractControllerIntegrationTest` 상속, 성공 + 주요 실패 경로(USERNAME_DUPLICATED, EMAIL_DUPLICATED, LOGIN_FAILED, USER_NOT_FOUND, VALIDATION_FAILED, UNAUTHORIZED) 검증.
- [ ] 각 테스트가 `document("auth/post-signup", ...)` 등 7개 고유 스니펫 ID 로 REST Docs 호출.
- [ ] 빌드 후 `build/generated-snippets/{auth,members}/...` 디렉터리 7개 생성 확인.
- [ ] `./gradlew test --tests AuthControllerTest --tests MemberControllerTest` 그린.
