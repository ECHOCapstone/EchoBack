# 012. Learning — Track / Script / LearningStep 엔티티 및 카탈로그 리포지터리

## Goal
학습 카탈로그(글로벌, user FK 없음) 의 JPA 엔티티 3종과 카탈로그 전용 리포지터리를 도입한다.

## Prerequisites
- 007: member-user-entity-repository

## Acceptance Criteria
- [ ] `Track` (`@Table(name="tracks")`): `id`, `title`, `description`, `displayOrder`.
- [ ] `Script` (`@Table(name="scripts", indexes=@Index(name="ix_scripts_track", columnList="track_id, chapter_order"))`): `id`, `track`(@ManyToOne LAZY), `title`, `content`, `difficulty`(enum STRING), `preset`(boolean), `practiceWord`, `masteryBadgeName`, `chapterOrder`(nullable).
- [ ] `LearningStep` (`@Table(name="learning_steps")`): `id`, `script`(@ManyToOne LAZY), `kind`(enum INTRO/RECORD), `prompt`, `targetText`(null when INTRO).
- [ ] 정적 팩터리: `LearningStep.intro(script, prompt)`, `LearningStep.record(script, prompt, targetText)`. INTRO 에 targetText 비허용.
- [ ] 카탈로그 리포지터리 (사용자 FK 없음):
  - `TrackRepository.findAllByOrderByDisplayOrderAsc()`.
  - `ScriptRepository.findByTrack_IdOrderByChapterOrderAsc(Long trackId)`, `findByPresetTrueOrderBy...`.
  - `LearningStepRepository.findByScript_IdOrderByIdAsc(Long scriptId)`.
- [ ] `DataJpaTest` 가 인덱스 정의 + 정적 팩터리 + 카탈로그 쿼리 그린.
- [ ] `./gradlew test --tests LearningCatalogDataJpaTest --tests LearningStepFactoryTest` 그린.
