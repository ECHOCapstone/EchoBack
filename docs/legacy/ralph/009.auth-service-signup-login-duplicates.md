# 009. Auth — AuthService 가입/로그인/중복체크

## Goal
표준 가입·로그인·중복체크 흐름을 `AuthService` 로 도입한다. 비밀번호는 BCrypt 해시만 저장하고, 가입 직후 JWT 발급(201).

## Prerequisites
- 007: member-user-entity-repository
- 002: foundation-jwt-provider

## Acceptance Criteria
- [ ] `com.capstoneecho.echo_back.member.service.AuthService` (`@Service`, `@Transactional`).
- [ ] `signup(request): AuthTokenResponse` — `USERNAME_DUPLICATED` / `EMAIL_DUPLICATED` 사전 체크 후 `User.signup(...)` + `JwtProvider.issue(...)` 발급. HTTP 201 매핑은 컨트롤러 책임.
- [ ] `login(request): AuthTokenResponse` — username/email 모두 허용. BCrypt 매칭 실패 시 `BusinessException(LOGIN_FAILED)`.
- [ ] `checkUsername(value)` / `checkEmail(value)` — `existsBy*` 결과만 반환 (DTO: `{available: boolean}`).
- [ ] `PasswordEncoder` Bean (`BCryptPasswordEncoder`) 을 `SecurityConfig` 가 제공하지 않았다면 본 task 에서 별도 `@Bean` 등록.
- [ ] DTO: `SignupRequest(username, email, password, nickname)`, `LoginRequest(usernameOrEmail, password)`, `AuthTokenResponse(token, expiresAt, profile: MemberProfileResponse)`.
- [ ] `AuthServiceTest` 가 정상 가입/로그인 + 중복 + LOGIN_FAILED + 평문 비밀번호 미저장 검증 그린.
- [ ] `./gradlew test --tests AuthServiceTest` 그린.
