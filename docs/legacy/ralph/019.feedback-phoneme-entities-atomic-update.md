# 019. Feedback — PronunciationFeedback / PhonemeError 엔티티 + atomic complete

## Goal
피드백·약점음소 엔티티를 도입하고, 완료 처리를 단일 UPDATE 로 수행하는 `markCompletedAtomically` 를 리포지터리에 두어 동시성 idempotency 를 확보한다. IMPLEMENTATION_PLAN §7.2 #3 본 task 책임.

## Acceptance Criteria
- [ ] `PronunciationFeedback` (`@Table(name="pronunciation_feedbacks", indexes=@Index(name="idx_feedback_user_completed_at", columnList="user_id, completed_at"))`):
  - 필드: `id`, `user`, `script`(nullable, SET NULL), `session`(nullable, SET NULL), `title`, `accuracy`(0..100), `weakPhoneme`, `practiceWord`, `guidanceKr`, `completed`(boolean), `completedAt`(Instant nullable). + 세션 스냅샷(taskTitle/scriptText 필드, FK SET NULL 후에도 보존).
  - CHECK 제약: script XOR session (Recording 와 동일 패턴).
  - 정적 팩터리 `PronunciationFeedback.forScript(user, script, ...)`, `forSession(user, session, ...)` — cross-parent 거부.
- [ ] `PhonemeError` (`@Table(name="phoneme_errors")`): `id`, `feedback`(@ManyToOne), `op`(enum SUB/DEL/INS), `canonical`, `perceived`, `canonicalIndex`. `feedback.attach(phonemeError)` 내부 메서드로만 생성.
- [ ] `FeedbackRepository extends JpaRepository<PronunciationFeedback, Long>`:
  - `findByIdAndUser_Id(id, userId)`.
  - `findAllByUser_IdOrderByCompletedAtDesc(userId)`.
  - `@Modifying @Query int markCompletedAtomically(@Param("id") Long id, @Param("userId") Long userId, @Param("now") Instant now)` — `UPDATE pronunciation_feedbacks SET completed=true, completed_at=:now WHERE id=:id AND user_id=:userId AND completed=false`. 반환 0 = 이미 완료 또는 미존재.
- [ ] 서비스 도메인 불변식 테스트:
  - **#3** `FeedbackFactoryTest::forScriptRejectsCrossParent`, `forSessionRejectsCrossParent`.
- [ ] `./gradlew test --tests FeedbackFactoryTest --tests FeedbackRepositoryDataJpaTest` 그린.
