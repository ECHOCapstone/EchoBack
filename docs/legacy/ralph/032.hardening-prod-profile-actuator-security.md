# 032. Hardening — 운영 프로파일 + Actuator 보안 분리

## Goal
`application-prod.yaml` 을 도입하고 Actuator 엔드포인트를 별도 보안 정책으로 분리한다.

## Prerequisites
- 031: hardening-jacoco-asciidoctor-gate

## Acceptance Criteria
- [ ] `application-prod.yaml`:
  - MySQL HikariCP 풀 설정 (maxPoolSize, connectionTimeout).
  - 로그 레벨 (`root: INFO`, `com.capstoneecho: INFO`).
  - 멀티파트 한도 25MB.
  - JWT 시크릿은 `${JWT_SECRET}` 환경변수 참조 (하드코딩 금지).
  - 모델 서버 URL `${MODEL_SERVER_BASE_URL}`.
  - 시간대 UTC 로그, KST stats zone.
- [ ] Actuator 보안 분리:
  - `/actuator/health` permitAll.
  - 그 외 `/actuator/**` 는 권한 `ROLE_ADMIN` 또는 별도 포트 분리 (정책 결정은 본 task 에서 ADR 형태 코멘트 또는 별도 issue 로 위임).
  - `management.endpoints.web.exposure.include` 운영에서 `health, info` 만.
- [ ] `ProdProfileSmokeTest` (`@ActiveProfiles("prod")` + 환경변수 stub) 가 부트업 검증 그린.
- [ ] `./gradlew test --tests ProdProfileSmokeTest` 그린.
