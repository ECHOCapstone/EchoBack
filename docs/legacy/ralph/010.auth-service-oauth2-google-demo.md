# 010. Auth — OAuth2 Google 데모 (upsert + 로그인 머지)

## Goal
실 OAuth2 client 흐름 없이, `GET /api/auth/oauth2/google/demo` 가 데모 이메일로 사용자를 멱등 upsert 하고 JWT 를 발급하도록 한다. 동일 이메일이 표준 가입으로 이미 존재하면 로그인 방식을 머지한다.

## Prerequisites
- 009: auth-service-signup-login-duplicates

## Acceptance Criteria
- [ ] `AuthService.loginWithGoogleDemo(): AuthTokenResponse` 메서드 (`@Transactional`).
  - 데모 이메일/닉네임은 `AppProperties.oauth2.googleDemo.email` / `.nickname` 또는 컴파일 상수로 픽스 (`demo+google@echo.app` 등).
  - 존재하지 않으면 `User.fromOAuth2(...)` 로 생성.
  - 존재하면 `user.mergeOAuth2Login()` 호출 후 동일 사용자에 JWT 발급.
  - 멱등: 동일 데모 이메일로 N회 호출해도 `users` row 1개만 생성됨.
- [ ] `AuthServiceTest` 에 다음 케이스 추가 + 그린:
  - 신규 데모 이메일 → 새 User 생성 + JWT 발급.
  - 동일 이메일 기존 표준 가입자 존재 → 머지(단일 row 유지) + JWT 발급.
- [ ] `./gradlew test --tests AuthServiceTest` 그린.
