# 025. Feedback Service — generate / retryWord / complete (atomic + EXP 보상)

## Goal
누적 녹음으로부터 통합 피드백을 생성, 약점 단어 재시도, 완료 + 보상 확정을 담당하는 `FeedbackService` 를 도입한다. `MemberService.awardCompletionRewards` 도 본 task 에서 추가. 서비스 도메인 불변식 #7, #8, #9, #10 본 task 책임.

## Acceptance Criteria
- [ ] `FeedbackService` (`@Service`, `@Transactional`):
  - `generate(userId, request): FeedbackDetailResponse` — script-flow / session-flow 컨텍스트 정합 검증 (#8 cross-context 거부), orphan recording 허용 처리 (#9), LLM `summarizeFeedback` 호출 + `PronunciationFeedback.forXxx(...)` 저장 + PhonemeError attach.
  - `retryWord(userId, feedbackId, audio, wordIndex): FeedbackDetailResponse` — 재시도 녹음 1건 추가 + `retryGuidance` 호출 + feedback 업데이트.
  - `complete(userId, feedbackId): FeedbackDetailResponse` — `feedbackRepository.markCompletedAtomically(id, userId, now)` 반환값 검사. 1 이면 `MemberService.awardCompletionRewards(userId, expReward)` 호출. 0 이면 미존재(`FEEDBACK_NOT_FOUND`) 또는 이미 완료(멱등 OK) 분기 명확화.
- [ ] `MemberService.awardCompletionRewards(userId, expReward)` 추가 — `User.recordCompletion(now, expReward, statsZone)` 호출, streak 7 cap, exp 누적, lastStudyAt 갱신.
- [ ] `ScoringPolicy` / `WeakPhonemeAnalyzer` / `PracticeWordResolver` / `PronunciationPromptBuilder` 지원 클래스 도입 — COMPONENTS_REFINED §5 참고.
- [ ] 서비스 도메인 불변식 테스트:
  - **#7** `FeedbackServiceConcurrencyTest::completeCalledTwiceAddsExpExactlyOnce` — `ExecutorService` 로 2 동시 호출, EXP delta = expReward.
  - **#8** `FeedbackServiceTest::generateCrossContextRejectsScriptAndSession`.
  - **#9** `FeedbackServiceTest::orphanRecordingsAreAggregatedSuccessfully`.
  - **#10** `FeedbackServiceTest::completeOtherUsersFeedbackReturns404`.
- [ ] `./gradlew test --tests FeedbackServiceTest --tests FeedbackServiceConcurrencyTest` 그린.
