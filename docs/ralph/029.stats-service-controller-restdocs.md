# 029. Stats — StatsService / StatsController + REST Docs (1 엔드포인트)

## Goal
사용자별 누적 통계(streak/exp/월별 출석/약점 음소/뱃지) 엔드포인트를 노출한다. 출석은 `completed_at` 을 KST 로 변환 후 일자 버킷팅, streak cap=7. 서비스 도메인 불변식 #13, #14 본 task 책임.

## Acceptance Criteria
- [ ] `StatsService` (`@Service`, `@Transactional(readOnly=true)`):

  - 출석 일자 버킷팅: `FeedbackRepository.findCompletedDatesByUser(userId, monthRange)` → KST 변환 → `Set<LocalDate>`. `AppProperties.stats.zone` 기반 (기본 `Asia/Seoul`).
  - `BadgePolicy` 도입 — 마스터리 뱃지 인벤토리 산출.
