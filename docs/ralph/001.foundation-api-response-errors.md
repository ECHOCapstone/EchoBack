# 001. Foundation — ApiResponse / ErrorCode / 글로벌 예외 처리

## Goal
모든 컨트롤러가 공유하는 응답 봉투 `ApiResponse<T>`, 19종 `ErrorCode`, `BusinessException`, 그리고 이를 일관 매핑하는 `GlobalExceptionHandler` 를 도입한다.

## Prerequisites
- 000: foundation-app-properties

## Acceptance Criteria
- [ ] `com.capstoneecho.echo_back.global.common.ApiResponse<T>` 가 `success`, `data`, `errorCode`, `errorMessage` 필드 + `@JsonInclude(NON_NULL)` 적용.
- [ ] `ApiResponse.success(data)`, `ApiResponse.failure(ErrorCode, message)` 정적 팩터리 제공.
- [ ] `ErrorCode` enum 이 IMPLEMENTATION_PLAN §2.3 의 19종을 모두 정의: 400 `INVALID_REQUEST`/`VALIDATION_FAILED`/`AUDIO_DECODE_FAILED`, 401 `UNAUTHORIZED`/`INVALID_TOKEN`/`LOGIN_FAILED`, 404 `USER_NOT_FOUND`/`TRACK_NOT_FOUND`/`SCRIPT_NOT_FOUND`/`STEP_NOT_FOUND`/`SESSION_NOT_FOUND`/`SESSION_SENTENCE_NOT_FOUND`/`RECORDING_NOT_FOUND`/`FEEDBACK_NOT_FOUND`, 409 `USERNAME_DUPLICATED`/`EMAIL_DUPLICATED`, 500 `INTERNAL_ERROR`, 502 `MODEL_SERVER_ERROR`, 503 `MODEL_SERVER_UNAVAILABLE`.
- [ ] `BusinessException(ErrorCode, message)` 가 `RuntimeException` 상속.
- [ ] `GlobalExceptionHandler` (`@RestControllerAdvice`) 가 `BusinessException`, `MethodArgumentNotValidException`, `MaxUploadSizeExceededException`, 일반 `Exception` 을 매핑하여 `ApiResponse` 봉투 + HTTP status 반환.
- [ ] `GlobalExceptionHandlerSliceTest` 가 19개 ErrorCode 각각의 status 와 JSON 응답을 검증 + 그린.
- [ ] `./gradlew test --tests GlobalExceptionHandlerSliceTest` 그린.
