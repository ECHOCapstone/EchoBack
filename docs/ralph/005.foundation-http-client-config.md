# 005. Foundation — HttpClientConfig (JDK HttpClient HTTP/1.1)

## Goal
모델 서버·TTS·LLM 어댑터가 공유할 `java.net.http.HttpClient` Bean 을 구성한다. HTTP/2 multipart 호환성 문제 회피를 위해 HTTP/1.1 강제.

## Prerequisites
- 000: foundation-app-properties

## Acceptance Criteria
- [ ] `com.capstoneecho.echo_back.global.config.HttpClientConfig` 가 `HttpClient` Bean 제공:
  - `version(HttpClient.Version.HTTP_1_1)`.
  - `connectTimeout(Duration.ofMillis(AppProperties.modelServer.timeoutMs))`.
- [ ] `RestClient` Bean 도 등록 (Spring 6.1+) — 동일 timeout 적용한 `JdkClientHttpRequestFactory` 사용.
- [ ] `HttpClientConfigTest` 가 Bean 의 `version()` 이 `HTTP_1_1` 인지 + `connectTimeout` 이 설정값과 일치하는지 검증 그린.
- [ ] `./gradlew test --tests HttpClientConfigTest` 그린.
