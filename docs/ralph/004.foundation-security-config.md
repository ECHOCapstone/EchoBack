# 004. Foundation — SecurityConfig 및 CORS

## Goal
stateless Security 체인을 구성하고 `permitAll` 화이트리스트와 JWT 필터 위치를 확정한다. CORS 도 `AppProperties` 기반으로 설정한다.

## Prerequisites
- 003: foundation-jwt-auth-filter

## Acceptance Criteria
- [ ] `com.capstoneecho.echo_back.global.security.SecurityConfig` 가 `SecurityFilterChain` Bean 제공:
  - CSRF disable, session `STATELESS`, formLogin/httpBasic disable.
  - permitAll: `/api/auth/**`, `/api/health`, `/error`, `/actuator/health`.
  - 그 외 `/api/**` 는 `authenticated()`.
  - `JwtAuthFilter` 를 `UsernamePasswordAuthenticationFilter` 앞에 등록.
  - 인증 실패 시 `JwtAuthEntryPoint`.
- [ ] `com.capstoneecho.echo_back.global.config.WebMvcConfig` 가 `AppProperties.cors` 기반 CORS 설정 + `CurrentUserArgumentResolver` 등록. 메서드 GET/POST/PUT/PATCH/DELETE/OPTIONS, `expose: Authorization, Content-Disposition`, `allowCredentials=true`, `maxAge=3600`.
- [ ] `SecurityConfigIntegrationTest` 가: permitAll 경로는 미인증 200/4xx (보호되지 않음 검증), `/api/**` 보호 경로는 미인증 401 + `ApiResponse(UNAUTHORIZED)` 봉투 케이스 그린.
- [ ] `./gradlew test --tests SecurityConfigIntegrationTest` 그린.
