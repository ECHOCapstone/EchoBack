# 022. LLM — LlmClient 인터페이스 + 룰 기반 기본 구현

## Goal
피드백 생성·녹음 요약·재시도 가이드·연습 단어 추천을 위한 `LlmClient` 인터페이스와 LLM 호출 없는 룰 기반 기본 구현을 도입한다.

## Prerequisites
- 019: feedback-phoneme-entities-atomic-update

## Acceptance Criteria
- [ ] `com.capstoneecho.echo_back.external.llm.LlmClient` 인터페이스 메서드 4개:
  - `summarizeRecording(LlmContext): RecordingGuidance(guidanceKr, wrongWords[])` — RecordingService.upload 단계.
  - `summarizeFeedback(LlmContext): String guidanceKr` — FeedbackService.generate 단계.
  - `retryGuidance(LlmContext): String guidanceKr` — FeedbackService.retryWord 단계.
  - `suggestPracticeWord(LlmContext): String` — PracticeWordResolver 폴백.
  - 모든 메서드의 `guidanceKr` 은 폴백으로 non-empty 보장. `wrongWords` 는 빈 배열 허용.
- [ ] `LlmContext` DTO: targetText, perceived, canonical, errors, weakPhoneme 등 필요한 컨텍스트 캐리어.
- [ ] `RuleBasedLlmFeedbackGenerator` (`@Component`, `@ConditionalOnProperty(name="app.llm.provider", havingValue="rule-based", matchIfMissing=true)`):
  - LLM 호출 없음.
  - `summarizeRecording`: `errors.canonicalIndex` + targetText 단어 경계로 wrongWords 산출 (없으면 빈 배열).
  - `guidanceKr` 폴백: 한국어 정형 템플릿 ("좀 더 또렷하게 발음해 보세요" 등).
- [ ] `RuleBasedLlmFeedbackGeneratorTest` 가:
  - errors 없음 → wrongWords 빈 배열 + non-empty guidance.
  - errors 있음 → wrongWords 가 해당 단어 포함 (IMPLEMENTATION_PLAN §7.2 #15 wrongWords 비/유 케이스).
- [ ] `./gradlew test --tests RuleBasedLlmFeedbackGeneratorTest` 그린.
