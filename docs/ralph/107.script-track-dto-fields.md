# 107. Script + Track — DTO 필드명 정렬 (D12)

## Goal

FRONT_API_SPEC §12 정렬: 스크립트 DTO 가 `isPreset` 필드명을 사용해야 하고 (현재 `preset`), 트랙 DTO 가 `chapterCount` / `displayOrder` 등 spec 의 모든 필드를 포함해야 한다. Jackson record 직렬화는 컴포넌트명을 그대로 키로 쓰므로 record 필드명을 spec 과 정확히 일치하도록 변경한다.
