# 021. Model Server — ModelServerClient (RestClient, /analyze + /g2p)

## Goal
모델 서버의 `/g2p` 와 `/analyze` 두 엔드포인트를 호출하는 concrete `@Component` (`RestClient` 기반) 어댑터를 도입한다. COMPONENTS_REFINED §1.2 정책에 따라 인터페이스 없이 concrete.

## Prerequisites
- 005: foundation-http-client-config

## Acceptance Criteria
- [ ] `com.capstoneecho.echo_back.external.modelserver.ModelServerClient` (`@Component`):
  - `g2p(text): G2pResult` — `POST /g2p` (form, `text` 필드).
  - `analyze(audioBytes, canonicalArpabetSpaceSep): AnalyzeResult` — `POST /analyze` multipart `audio` + optional `canonical`.
  - `ResourceAccessException`/timeout → `BusinessException(MODEL_SERVER_UNAVAILABLE)` (503).
  - `RestClientResponseException` (4xx/5xx) → `BusinessException(MODEL_SERVER_ERROR)` (502).
  - 타임아웃 `AppProperties.modelServer.timeoutMs`, 재시도 없음, 인증 없음.
  - Jackson camelCase 매핑.
- [ ] DTO: `G2pResult(phonemes, words: List<G2pWord>)`, `G2pWord(word, phonemes: List<String>)`, `AnalyzeResult(perceived: List<String>, canonical: Optional<List<String>>, peakSoftmax: List<Double>, alignment: List<?>, errors: List<AnalyzeError>, per: Optional<Double>, durationSec: double)`, `AnalyzeError(op, canonicalIndex, perceived, canonical)`.
- [ ] `ModelServerClientTest` (MockWebServer 또는 `@RestClientTest`) 가:
  - 정상 g2p / analyze JSON 매핑 그린.
  - 5xx → MODEL_SERVER_ERROR (502).
  - 타임아웃/네트워크 단절 → MODEL_SERVER_UNAVAILABLE (503).
- [ ] `./gradlew test --tests ModelServerClientTest` 그린.
