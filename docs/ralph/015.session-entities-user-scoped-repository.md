# 015. Session — Session / SessionSentence 엔티티 + 사용자 스코프 리포지터리

## Goal
사용자 세션(커스텀 학습 스크립트) 의 JPA 엔티티 2종과 사용자 스코프 리포지터리를 도입한다.

## Prerequisites
- 012: learning-track-script-step-entities

## Acceptance Criteria
- [ ] `Session` (`@Table(name="sessions")`): `id`, `user`(@ManyToOne LAZY, NOT NULL), `title`, `scriptText`(NOT NULL, 초기값 빈 문자열), `favorite`(boolean), `createdAt`, `updatedAt`. 정적 팩터리 `Session.create(user, title)` 가 `scriptText=""`, `favorite=false` 로 초기화.
- [ ] `SessionSentence` (`@Table(name="session_sentences", indexes=@Index(name="ix_session_sentences_session", columnList="session_id, sentence_index"))`): `id`, `session`(@ManyToOne LAZY), `sentenceIndex`(int), `text`. 외부 생성 금지, `Session` 내부에서만 생성.
- [ ] `Session.updateScript(newScriptText, sentenceSplitter)` 가 sentences 컬렉션을 통째로 교체(`orphanRemoval=true` + `clear()+addAll()`).
- [ ] 사용자 스코프 리포지터리:
  - `SessionRepository.findByIdAndUser_Id(Long id, Long userId)` — 옵션, 미존재 시 빈 Optional.
  - `SessionRepository.findAllByUser_IdOrderByUpdatedAtDesc(Long userId)`.
  - `SessionRepository.deleteByIdAndUser_Id(Long id, Long userId): int` (영향 행 수 반환).
  - `SessionSentenceRepository` 도 필요 메서드만 사용자 스코프 (직접 조회는 거의 안 함; Session 통한 cascade 가 기본).
- [ ] `@DataJpaTest` 가 ix_session_sentences_session 인덱스 + 사용자 스코프 lookup + Session.updateScript 가 sentences orphan-remove 그린.
- [ ] `./gradlew test --tests SessionDataJpaTest` 그린.
