# 000. Foundation — AppProperties 및 환경 프로파일

## Goal
어플리케이션 전역 설정의 단일 출처인 `AppProperties` 와 `application-{local,test}.yaml` 을 도입한다. 이후 모든 Foundation/도메인 task 가 의존하는 base config 다.

## Prerequisites
없음.

## Acceptance Criteria
- [ ] `com.capstoneecho.echo_back.global.config.AppProperties` (`@ConfigurationProperties("app")`) 가 다음 그룹을 보유: `jwt(secret, expirationMs)`, `cors(allowedOrigins, allowedMethods, exposedHeaders, allowCredentials, maxAgeSec)`, `modelServer(baseUrl, timeoutMs)`, `llm(provider)`, `storage(localRoot)`, `tts(provider)`, `stats(zone)`.
- [ ] `src/main/resources/application.yaml` 은 `spring.application.name` 만 유지, 환경별 값은 `application-local.yaml` / `application-test.yaml` 에 분리.
- [ ] `application-test.yaml` 에 H2 in-memory MySQL 모드 datasource (`jdbc:h2:mem:testdb;MODE=MySQL`, `ddl=create-drop`), 멀티파트 한도 25MB, KST 시간대(`Asia/Seoul`), `app.llm.provider=rule-based`, `app.tts.provider=local-stub` 락인.
- [ ] `AppPropertiesTest` 가 `@SpringBootTest(properties=...)` 로 모든 prefix 바인딩을 검증 + 그린.
- [ ] `./gradlew test --tests AppPropertiesTest` 그린.

## TDD Entry Points
- `com.capstoneecho.echo_back.global.config.AppPropertiesTest::bindsAllGroups`
- `com.capstoneecho.echo_back.global.config.AppPropertiesTest::testProfileLoadsH2Datasource`

- 신규: `src/test/java/com/capstoneecho/echo_back/global/config/AppPropertiesTest.java`
