# 102. TTS — `/api/tts` 공개화 + `lang` 필드 (D1+D8)

## Goal

FRONT_API_SPEC §11 + §12 정렬: `POST /api/tts` 를 JWT 보호에서 공개(permitAll) 로 전환하고, 요청 필드 `locale` 을 `lang` 으로 rename 한다. `TtsController` 의 미사용 `@CurrentUser` 파라미터 제거, `TtsService` 가 새 `lang` 필드를 소비하도록 수정한다.
