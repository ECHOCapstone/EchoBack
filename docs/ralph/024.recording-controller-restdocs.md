# 024. Recording — RecordingController + REST Docs (1 엔드포인트, multipart)

## Goal
`POST /api/recordings` 멀티파트 엔드포인트를 노출하고 REST Docs 스니펫을 생성한다.

## Prerequisites
- 023: recording-service-upload-txn-sync
- 017: session-controller-restdocs

## Acceptance Criteria
- [ ] `RecordingController` (`@RequestMapping("/api/recordings")`, JWT 필요):
  - `POST /` — `multipart/form-data`: `audio` (필수, 25MB 한도), `scriptId`/`stepId`/`sessionId`/`sessionSentenceId` 중 적절 조합. 201 + RecordingUploadResponse.
- [ ] 컨트롤러 테스트 (`AbstractControllerIntegrationTest` 상속) 가:
  - script-flow / session-sentence / session-free-form 3 모드 성공 케이스.
  - `INVALID_REQUEST` (parent 미지정), `AUDIO_DECODE_FAILED`, `SCRIPT_NOT_FOUND`, `SESSION_NOT_FOUND`, `STEP_NOT_FOUND`, `SESSION_SENTENCE_NOT_FOUND` 매핑.
  - `MODEL_SERVER_ERROR` (502), `MODEL_SERVER_UNAVAILABLE` (503) — `@MockitoBean ModelServerClient` 으로 시뮬레이션.
  - REST Docs 스니펫 `recordings/upload` (multipart 문서화 포함).
- [ ] `WavFixtures` / `AnalyzeMockResponses` / `LlmMockResponses` 픽스처를 `src/test/java/.../support/` 에 도입.
- [ ] `./gradlew test --tests RecordingControllerTest` 그린.
