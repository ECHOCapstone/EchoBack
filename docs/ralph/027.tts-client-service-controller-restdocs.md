# 027. TTS — TtsClient / TtsService / TtsController + REST Docs (1 엔드포인트, raw bytes)

## Goal
영문 텍스트 → MP3 raw bytes 응답 엔드포인트를 노출한다. 1차는 로컬 스텁 구현(ID3 magic 포함 ~100 bytes non-empty MP3 반환).

## Acceptance Criteria
- [ ] `com.capstoneecho.echo_back.pronunciation.tts.support.TtsClient` 인터페이스: `byte[] synthesize(String text, Locale locale)`.
- [ ] `DefaultTtsClient` (`@Component`, `@ConditionalOnProperty(name="app.tts.provider", havingValue="local-stub", matchIfMissing=true)`):
  - 반환 바이트는 ID3 헤더 magic (`0x49 0x44 0x33`) 포함 non-empty ~100 bytes 고정 MP3. (API_TEST_PLAN §3.26 골든 테스트 `body length > 0` 통과.)
- [ ] `TtsService.synthesize(request): byte[]` — `text` 빈/공백 → `INVALID_REQUEST`. (모델 서버 의존 시 502/503 매핑 자리 표시는 향후 외부 프로바이더 추가 시 활성화.)
- [ ] `TtsController` (`@RequestMapping("/api/tts")`, JWT 필요):
  - `POST /` — Body: `{text, locale?}`. **200 응답은 raw MP3 bytes (ApiResponse 봉투 예외 — IMPLEMENTATION_PLAN §2.2 글로벌 결정)**. Content-Type `audio/mpeg`. 에러 응답은 평상시처럼 `ApiResponse` 봉투 JSON.
- [ ] `TtsControllerTest` 가:
  - 정상 200 + body length > 0 + Content-Type `audio/mpeg` + 첫 3바이트 = `ID3`.
  - 빈 text → 400 INVALID_REQUEST (ApiResponse 봉투).
  - REST Docs 스니펫 `tts/synthesize` (응답이 raw bytes 인 점 명시).
- [ ] `./gradlew test --tests TtsControllerTest` 그린.
