# 103. Recording — `SESSION_FREE_FORM` 모드 제거 (D3 + D2 verify)

## Goal

FRONT_API_SPEC §7 정렬: `POST /api/recordings` 의 canonical mode 를 `script-flow` + `session-sentence` 2가지로 단일화한다. `RecordingService.detectMode` 의 `SESSION_FREE_FORM` 분기, `Mode` enum 값, switch case 2개, `Recording.forSessionFreeForm` 정적 팩토리, 그리고 관련 테스트를 제거/교체한다. `sessionId`-only multipart 요청은 `INVALID_REQUEST` (400) 로 거절된다.

D2 (form-data field) 는 `RecordingControllerTest` 의 `.param(...)` 호출이 multipart form 필드 형태로 보내므로 본 task 의 test green 이 자연스럽게 검증한다 — 별도 코드 변경 없음.

또한 권위 문서 `ENTITIES_REFINED.md` §2.7 의 Recording 정적 팩토리 목록에서 `forSessionFreeForm` 항목을 제거해 코드와 일치시킨다.

- 100 (envelope-and-error-shape) — 에러 응답 형태 정렬 후. 102/103/104/105/106/107 와 병렬 가능.
