# 003. Foundation — JwtAuthFilter / JwtAuthEntryPoint

## Goal
요청 헤더의 `Authorization: Bearer <token>` 을 파싱해 SecurityContext 를 채우는 필터, 그리고 인증 실패 시 `ApiResponse` 봉투로 401 을 반환하는 EntryPoint 를 도입한다.

## Prerequisites
- 002: foundation-jwt-provider

## Acceptance Criteria
- [ ] `com.capstoneecho.echo_back.global.security.JwtAuthFilter` 가 `OncePerRequestFilter` 상속. `Authorization` 헤더가 없으면 통과(downstream 에서 EntryPoint 가 처리), 있으면 `JwtProvider.parse` 호출 후 `SecurityContextHolder` 채움.
- [ ] 파싱 예외(`INVALID_TOKEN`/`UNAUTHORIZED`)는 request attribute 에 보관해 EntryPoint 가 적절한 ErrorCode 로 매핑.
- [ ] `JwtAuthEntryPoint` 가 `ApiResponse.failure(UNAUTHORIZED|INVALID_TOKEN, ...)` JSON 으로 401 응답.
- [ ] `JwtAuthFilterTest` (`@WebMvcTest` 또는 단위) 가: 토큰 없음 → 401 UNAUTHORIZED, 만료 → 401 INVALID_TOKEN, 위조 → 401 INVALID_TOKEN 3 케이스 그린.
- [ ] `./gradlew test --tests JwtAuthFilterTest` 그린.
