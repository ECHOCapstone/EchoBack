# 020. Recording Storage — RecordingStorage 인터페이스 + LocalRecordingStorage 구현

## Goal
오디오 파일 저장/삭제를 추상화한 `RecordingStorage` 인터페이스와 로컬 디스크 구현체를 도입한다. 경로 패턴 `userId/yyyyMM/uuid.wav`, delete idempotent.

## Prerequisites
- 000: foundation-app-properties

## Acceptance Criteria
- [ ] `com.capstoneecho.echo_back.pronunciation.recording.support.RecordingStorage` 인터페이스:
  - `String save(long userId, byte[] wavBytes): audioPath` — 저장 경로 반환.
  - `void delete(String audioPath)` — 미존재 시에도 예외 없음(idempotent).
  - `byte[] read(String audioPath)` (테스트 용도 + 향후 다운로드 — 1차 구현 필수).
- [ ] `LocalRecordingStorage` (`@Component`):
  - 루트: `AppProperties.storage.localRoot`.
  - 경로 패턴: `<root>/<userId>/<yyyyMM>/<UUID>.wav` (yyyyMM 은 `Instant.now()` UTC 기준).
  - `save` 는 디렉터리 자동 생성.
- [ ] `LocalRecordingStorageTest` (`@TempDir` 사용) 가:
  - save → read 라운드트립.
  - delete 후 read 가 `IOException` 또는 명시 예외 throw.
  - delete on missing path → 예외 없음.
  - 동일 userId 로 N회 save 시 N개 고유 UUID 파일.
- [ ] `./gradlew test --tests LocalRecordingStorageTest` 그린.
