== 개요

본 문서는 ECHO 백엔드의 공개 API 레퍼런스다. Spring REST Docs 가 컨트롤러 테스트
실행 시 `build/generated-snippets/` 에 산출한 스니펫들을 도메인별로 묶어 단일
HTML 산출물(`build/docs/asciidoc/index.html`)로 통합한다.

도메인 구성은 `docs/API_SPEC_REFINED.md` §3·§4 의 5-도메인 분류
(Member / Learning / Pronunciation / Statistics / System) 를 따른다.
