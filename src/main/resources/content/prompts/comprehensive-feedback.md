# 종합 피드백 요청

한 챕터의 모든 step 학습이 끝났다. 챕터 전반의 흐름을 보고 종합 피드백 + 다음 학습 추천을 JSON 스키마에 맞춰 돌려준다.

## 챕터
- 제목: {{chapterTitle}}
- 내용: {{chapterContent}}

## 챕터 전체 통계
- 평균 정확도: {{overallAccuracy}}
- 가장 두드러진 약점 음소: {{dominantWeakPhoneme}}

## Step 별 최종 결과 (순서대로)
{{stepSummaries}}

## 챕터 누적 음소 오류 (op / canonical / perceived)
{{aggregatedErrors}}

## 출력 규칙

- `overallScore` 는 step 들의 best 점수 평균에 약점 음소 보정을 가감해 0~100 정수로 산출.
- `summaryKr` 은 챕터의 전체 인상 + 가장 큰 강점/약점 한 가지씩.
  - 약점 음소 (`dominantWeakPhoneme`) 의 아학편 표 행을 참조한다.
    - **한글 음차 열에 단어 발음 예시가 있고 학습자 오류 위치가 예시의 음소 위치와 일치하는 경우** (예: 어두 L 예시는 어두 L 오류에만, 어두 R 예시는 어두 R 오류에만): 그 중 서로 다른 2개를 표에 적힌 그대로 (예: `/(으)뤠드/`, `/(으)룰러/`) 인용해 자연스러운 문장 안에 녹인다. 한글이 반드시 포함되어야 하며, 영단어만 슬래시에 넣지 않는다.
    - **위치가 다르거나 예시가 없는 경우** (예: 어말 L 오류에 어두 L 예시 사용 금지):
      - `chapterContent` (또는 `stepSummaries`) 에서 **해당 음소·위치가 등장하는 단어를 1개 골라** 구체적인 예로 든다.
      - 형식: `'<chapterContent 에서 고른 단어>' 같은 단어의 [단어 맨 앞/끝 등 위치] [소리]를 낼 때는, [몸으로 할 동작 한 줄]` (전문 용어 대신 일상어로)
        - 실제 예 (chapterContent="I fell for you", 약점=단어 끝 L): "'fell' 같은 단어의 끝 'L' 소리를 낼 때는, 혀끝을 윗니 바로 뒤 잇몸에 꼭 대고 소리를 흘려보냅니다."
        - **`chapterContent` 에 등장하지 않는 단어 (표 예시, 일반 단어 등) 를 임의로 끌어다 쓰지 않는다.**
      - 단서 부분은 같은 행의 "입 모양 · 혀 위치 단서" 열 내용을 그대로 풀어 쓴다.
      - 다른 행의 예시를 끌어다 쓰거나 표에 없는 슬래시 형식을 만들지 않는다.
- `strengths` / `weaknesses` 는 각각 2~4 개. 학습자가 다음 챕터로 들고 갈 만한 것들로.
- `nextPracticeItems` 는 3~5 개. **단어 / 구 / 문장이 적절히 섞이도록** 추천하라.
  - WORD: 약점 음소가 두드러지는 단음절~다음절 영어 단어
  - PHRASE: 자주 같이 쓰이는 짧은 구 (2~4 단어)
  - SENTENCE: 약점 음소가 여러 번 등장하는 자연스러운 영어 문장
  - 각 항목의 `reason` 은 학습자에게 노출되는 추천 사유 한 줄.
