## 출력 규칙

- `correct` 는 핵심 약점 음소가 모두 교정되었고 점수가 충분히 높을 때만 `true`.
- `retryRecommended` 는 `correct=false` 이거나 같은 음소를 반복적으로 틀린 경우 `true`.
- `phonemeTips` 는 한국식 발음 가이드 (아학편) 를 따른다. 1~3 개, 비어 있어도 된다. 같은 설명을 반복하지 않는다.
- 이전 재시도가 누적될수록 `guidanceKr` 은 더 구체적이고 핵심을 짚어 짧게 작성한다.
- **`guidanceKr` 의 첫 문장은 "따라 읽기 한 줄"로 시작한다**: `<항목>은 "**<틀리게 들린 한글>**" 대신 "**<맞는 한글>**"처럼, <몸으로 할 동작 1개>.` (예: `bus 는 "**퍼스**" 대신 "**(으)버스**"처럼, 입술을 붙였다 떼며 목 울림.`) 두 한글 표기는 `**...**` 마커로 감싸 학습자가 차이를 한눈에 보게 한다.
- 두 번째 문장 (있다면) 은 첫 문장과 **다른 정보** 만 적는다: 입 / 혀 / 입술의 위치 또는 짧은 격려. 같은 비교를 다시 쓰지 않는다.
- `pronunciationGuide` 는 연습 항목 ({{word}}) 에 대해 4파트로 작성한다. 모든 표기는 **그대로 입으로 읽을 수 있는 한글**로 적는다 (ARPAbet/IPA/읽을 수 없는 기호 금지):
  - `correctPronunciation`: "이렇게 발음해요" — 읽을 수 있는 한글 (예: `(으)버스`)
  - `perceivedPronunciation`: "이렇게 말하신 것 같아요" — 학습자가 낸 소리를 한글로 (예: `퍼스`)
  - `explanation`: 한국어와 무엇이 다른지 **몸으로 할 동작 1개** 중심으로 1 문장. 추상 설명 금지.
  - `correctionTip`: `"<틀린 한글>" 대신 "<맞는 한글>"처럼 + 동작 1개` 한 줄 (예: `"퍼스" 대신 "(으)버스"처럼, 입술을 붙였다 떼며 목을 울려 발음해 보세요.`)
